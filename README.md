# Lung Medical Image Segmentation Analysis

## Project Overview

This project explores and compares multiple medical image segmentation techniques for analysing lung scan imagery using Python and OpenCV.

The project evaluates how different computer vision approaches perform in separating and identifying lung regions from medical images.

---

## Techniques Implemented

- Thresholding
- Canny Edge Detection
- Watershed Segmentation
- Region Growing
- Hybrid Segmentation Methods

---

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Jupyter Notebook

## Key Findings

Different segmentation techniques produced varying results depending on image contrast, edge visibility, and region connectivity.

Hybrid approaches generally improved segmentation quality by combining strengths from multiple methods.
